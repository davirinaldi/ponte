# Security policy

Ponte runs a privileged agent on customer machines, so security reports are taken seriously.

**Do not open a public issue for a vulnerability.** Report it privately through GitHub's
"Report a vulnerability" button on this repository (Security tab). Include steps to
reproduce and the impact you expect.

Ponte is pre-alpha and not ready for production use. See `docs/threat-model.md` for the
threats the design addresses and the risks currently accepted.
